About

What is Palladium?

A Bitcoin fork built for speed, without sacrificing security.

Palladium inherits Bitcoin's cryptographic foundation — SHA-256 proof-of-work, a fixed supply, and a predictable halving schedule — while cutting block time from 10 minutes to 2. The result is a chain that is faster to confirm, easier to mine, and free from central control.

Why Palladium

Built for speed and security

Battle-tested security

Inherits Bitcoin's SHA-256 proof-of-work — the most attacked, most resilient consensus algorithm in crypto.

5x faster blocks

2-minute block times instead of Bitcoin's 10 — faster confirmations without changing the security model.

ASIC compatible

Same algorithm as Bitcoin means existing SHA-256 ASICs can mine Palladium with zero new hardware.

Fixed, predictable supply

Capped at 21,000,000 PLM with a halving every 210,000 blocks — no inflation, no surprises.

Solo mining pool

Poolladium, built on ckpool, pays block rewards directly to your address — no pooled fees, no middlemen.

100% open source

Every component — core, wallet, pool, explorer — is public and auditable on GitHub.
